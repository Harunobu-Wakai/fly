# 極楽スロット 戒名大当たり

パチンコ・スロット風の演出で戒名（かいみょう）を生成する、ネタ系Webアプリです。スマホ縦画面向けの単一HTMLファイルで、ビルド不要・依存関係なしで動きます。

`index.html` をブラウザで直接開くだけで遊べます。

## 遊び方

1. **スタート画面** — 漢字フルネームと性別を入力して「回す」。
2. **スロット画面** — 「院号／道号／戒名／位号」の4リールをレバーで回転。左から順に停止し、条件がそろうと「リーチ」→「激アツ」→「大当たり」へと演出が発展します。
3. **結果画面** — 縦書きの位牌風カードに戒名が表示されます。「もう一回」で再挑戦、「画像で保存」でカードをPNG画像としてダウンロードできます。

## 戒名の生成ルール

- **院号**：出現率10%。当選時は「○○院」。ハズレ時は空欄。
- **道号**：自然や徳を表す2文字からランダムに選出。
- **戒名**：1文字目は入力した名前の漢字からランダムに1字、2文字目は仏教的な漢字リストからランダムに1字。
- **位号**（性別で出し分け）：通常70%「信士／信女」、レア25%「居士／大姉」、院号当選時は確変「院居士／院大姉」。

## 演出

- **保留数珠**：スロット画面上部の数珠玉が白→青→金→虹の順で期待度を示します。
- **リーチ**：好条件のとき、木魚の音が加速しながら画面が暗転します。
- **激アツ**：大当たり確定の回では蓮の花が開き、後光が差します。
- **大当たり**：院号当選時は「㊗ 成仏確定!!」の文字とともに金色の紙吹雪が舞い、鐘の音が鳴ります。
- 効果音（木魚・鐘・リール停止音）はすべてWeb Audio APIでその場生成しており、外部の音声・画像ファイルは一切使用していません。

## 注意点

これは笑って楽しむためのネタアプリです。実際の戒名は、故人が生前に縁のあった菩提寺からいただくものであり、本アプリの生成結果に宗教的な効力はありません。
